本版以用户确认的“沙漠风暴明确配置优先”覆盖旧数值，详见 [兵种接入说明](../../docs/DESERT_STORM_UNITS.md)。单位与武器的实际运行数据仍在上一级 `data/units.json`。

- “兵种属性 / 武器模式 / 技能参数”是可编辑数据，新增每组瓦斯/灵核价格、固定扣血、部署护甲、分段出手时间表等字段。
- “沙漠风暴来源”记录逐字段原始节点；“沙漠风暴待确认”的黄色条目表示继承、映射或技能链未齐。来源未齐时保留项目回退值，不等于原图最终实战属性。
- 旧“技能核对”保留原版原型资料，已标为旧记录；不能据此判断当前技能已完整复刻。
- 价格按原图单体价格乘现有每组数量；医疗兵当前明确为380矿+380气。新买未出场取消退回所有已花资源，出场后不退款。

打开 `兵种配置.xlsx` 编辑数据页并保存，再执行 `python tools/import_units.py`，或交给AI导入。来源/待确认页是说明，不直接驱动运行；实际数值请在三个数据页中修改。黄色格有两种：旧审核的空白待填、新来源审核的保留回退值，分别以批注为准。不要删除隐藏源数据或路径行。

`tools/desert_storm_units.py --apply` 是开发者的参考覆盖生成工具，会覆盖映射字段；手动编辑当前数值后不要无意重跑。其账本在 `desert_storm_reference.json`，旧原版回退审核仍记录在 `sc2_reference.json`。

本版仅生成/更新数据和表格，不运行Godot导入、校验、测试、模拟或打包。已有APK/EXE需要另外打包才包含修改。

0.7.4：表格不再展示内部 damage_type，改为每轮命中次数 hit_count。伤害和对甲加成均指每段，护甲逐段扣除；武器模式可独立配置段数，溅射对每段生效。一轮只占用一次攻击冷却。当前多段在同一步内逐段结算；独立弹道/分段延迟需另行配置机制。
