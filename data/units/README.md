此目录保存供 Excel/WPS 编辑的当前兵种工作簿。运行时配置仍为上一级 `data/units.json`。

打开 `兵种配置.xlsx`，编辑“兵种属性”数据格或“武器模式 / 技能参数”F 列，保存后在仓库根目录执行 `python tools/import_units.py`。也可把编辑后的文件交给 AI 导入。详细规则在工作簿“填写说明”页及根目录 README 第十三节。

已收录全部 49 个单位和建筑。数值原样取自 0.7.5 当前代码，已包含医疗兵95生命、解放者架设炮65+30重甲，以及雷神各模式的独立段数和伤害。

需留意原有配置不一致：特工的技能武器覆盖顶层攻击属性（雷神三模式现已按0.7.4同步）；解放者对空溅射0、架设炮65+30重甲/1.14秒；大和炮720、选敌当前生命与护盾门槛300。请按实际设计分别编辑对应参数。

导入会保留表格未编辑的源码更新，遇到同字段并发修改报冲突，不会悄悄覆盖。请保留隐藏的“源数据”页，不删除参数行。已有 APK/EXE 需要重新打包才生效。

AI 工作流程：先同步 cloud/test → 用 `tools/import_units.py 文件.xlsx --check` 查看变更 → 导入 → 同时提交表格及 data/units.json。仅在用户要求检查时运行校验、模拟或测试。本次仅生成表格、实现工具并审阅源码，未运行导入校验或游戏检查。

0.7.4：表格不再展示内部 damage_type，改为每轮命中次数 hit_count。伤害和对甲加成均指每段，护甲逐段扣除；武器模式可独立配置段数，溅射对每段生效。一轮只占用一次攻击冷却。当前多段在同一步内逐段结算；独立弹道/分段延迟需另行配置机制。

0.7.5：恶火开火距离4.5、传播长度5；人族防御塔以terran_bunker独立模板收录（原tower继续用于其他种族）。独立炮位数量在武器模式页的count，单炮位每轮命中次数在hit_count，不要混淆。防御塔8套对空/对地武器（15伤害/6格/0.43秒）和2套对地武器（20+20重甲/7格/0.75秒）；HP1200、重甲、护甲3、建筑、无自然回血。
