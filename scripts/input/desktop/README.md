# 电脑输入

布阵板左键单击选一名，双击选全部同兵种（跨购买组），拖动框选；右键松开散布，按住至少 300ms 且移动至少 24 设计像素后松开按线排布。框选按兵员中心，8 设计像素启动；移出布阵板松开取消。框内有部队则排除建筑；仅建筑可显示选中但不可布置。

WASD 只控制战场镜头，斜向归一化，620 设计像素/秒，指数加速 10/s、减速 8/s；精确积分，单帧最多 0.1s 防止卡顿跳跃。缩放、模态界面、拖动、焦点丢失清理按键和惯性。原有战场鼠标拖动/滚轮不变。

防御塔选址时可用 WASD 或鼠标拖动平移，滚轮缩放。左键在战场上单击并松开后预览落点，确认建造后才消耗资源。在确认框中取消可重新选址。
