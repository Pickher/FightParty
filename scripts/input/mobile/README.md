# 手机输入

仅原生 ScreenTouch/ScreenDrag 进入触摸适配层；拒绝引擎模拟鼠标，避免一次触摸触发两次。保持按数量选兵、点选单兵、点空地散布、长按拖线（300ms + 24 设计像素）。第二根手指取消手势，全部抬起后才能重新操作。不附加电脑左右键或 WASD。

小地图触摸按下清理旧导航状态但保留当前手指，随后拖动/抬起正常完成。弹窗、重建、焦点丢失、切后台与重开对局清理捕获，不让遗留抬起穿透新界面。混合设备切换取消旧布阵手势，提交也校验触摸/鼠标来源。

防御塔选址期间，单指在战场上按下并于 450 毫秒内抬起、移动始终小于 12 设计像素时，显示该处的虚影和建造确认。移动达到 12 设计像素后改为平移镜头，拖回起点再松手也只结束平移。
