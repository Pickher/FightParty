# FightParty 游戏设计 v0.1

## 体验目标

玩家观察敌方已公开部队，用双方完全相同的收入逐步扩充永久兵营。胜负来自兵种克制、数量、站位与花钱时机，而非战场操作；没有击杀收入，避免资源滚雪球。首版为原创几何美术的 2D 横屏离线人机游戏，不含账号、联网、内购、养成数值或付费兵种。

## 一局的流程

打开游戏先布阵，点击“开始准备”启动 30 秒准备倒计时。此后每隔 30 秒双方同时生成一整波军队（整份兵营），战场不停，未死亡部队保留生命、冷却与位置并一直战斗到阵亡（0.2.0 起取消 90 秒撤离）。所有编辑只影响之后的波次。

（0.2.0 永久兵营）双方开局 600 矿物，每次出兵后各 +300，矿物结转，无击杀收入。在空格购买立即扣矿；本轮新买、未出场的单位取消退还 100%；出场过的单位可以取消但不退款，UI 需二次确认；取消只影响之后的波次，场上已有单位不受影响。移动/交换免费并保留出场状态。替换等于先卖后买。空兵营合法。所有操作连同 tick 写入战报。

每方兵营为 18 列 × 8 行，144 个单位名额（0.2.1 起，原 6×4）。出生区从 x=140 起每列间隔 13、从 y=32 起每行间隔 48，前排最右列约在 x=361，离中线仍有距离。UI 左侧为后排，右侧为前排；金色边框标出本轮新买、取消可全额退回的格子；敌方布阵映射为水平镜像。玩家点击卡片后点击格子放置或替换；“移除单位”后点击删除；“移动位置”先选源格再选目标格，已占格交换。

矿物不足、未知兵种（含结构体）、重复占格、非整数或越界格子均拒绝整个提交，保留原兵营。合法修改立即存盘。重开时用开局矿物尝试买回最近兵营，买不起则用默认 600 阵容，再买不起（例如开局 0 矿）则为空；用户明确保存的空兵营保留。

## 战场与胜负

战场逻辑大小 1200×400，基地位于 (30,200) 与 (1170,200)（坐标见 `rules.json` 的 `layout`，敌方按宽度镜像），均 3000 HP，无护甲和反击。单位优先与附近敌人交战，没有目标时向敌方基地推进；攻击基地不应用兵种护甲倍率。

基地归零即结束，同一模拟步两个基地同时归零为平局。第 64 波（`wave_limit`）出场后不再出兵、不再发收入；此后每步检查，某方没有可攻击部队（非结构体且伤害大于 0，医疗兵不算）即判负，双方同时没有为平局。最后一波后超过 600 秒（`final_phase_max_seconds`，安全阀）仍未结束，比较基地剩余血量，相等为平局。0.2.0 删除 8 分钟时限。暂停、手册和 Android 后台均暂停模拟与倒计时，不消耗对局时间。

## 初始兵种数值

权威数据是 `data/units.json`，版本 0.2.1。数值是可测试的原型起点，不代表商业版本已经完成平衡。

- 盾卫：100 预算，480 HP，重甲；伤害 16，间隔 1.2 秒，射程 25，速度 34；对轻甲 ×1.0，对重甲 ×0.8。
- 步枪兵：75 预算，120 HP，轻甲；伤害 18，间隔 0.55 秒，射程 140，速度 36；对轻甲 ×1.4，对重甲 ×0.45。
- 破甲手：125 预算，130 HP，轻甲；伤害 58，间隔 1.5 秒，射程 150，速度 32；对轻甲 ×0.65，对重甲 ×2.4。
- 蜂群兵：50 预算，90 HP，轻甲；伤害 15，间隔 0.55 秒，射程 22，速度 65；对轻甲 ×1.0，对重甲 ×0.7。
- 迫击炮：150 预算，100 HP，轻甲；伤害 90，间隔 2.8 秒，射程 300，速度 26；半径 70 的敌军范围伤害；对轻甲 ×1.2（108）、对重甲 ×1.5（135），不伤友军。架设 1.5 秒后才能开火，收起耗时 1 秒，转换期间不能移动或攻击。
- 狙击手：150 预算，75 HP，轻甲；伤害 100，间隔 2.5 秒，射程 220，速度 30；对轻甲 ×1.4，对重甲 ×0.35。未开火时在发现范围（射程的 150%）内优先选择低基础生命目标；开火后保持锁定，直到目标死亡、撤离或离开攻击范围。

距离以逻辑单位计，速度为逻辑单位/秒。实际攻击时间量化到 0.05 秒模拟步；普通攻击在开火步结算；穿刺者地刺与巨像扫射在传播到达时结算。

预期关系：破甲手克盾卫；步枪兵克轻甲；迫击炮克密集蜂群；蜂群克孤立狙击；迫击炮可凭射程压制狙击，但在架设前被狙击手进入射程突袭时仍会被一枪击杀。组合、距离和分散布阵会改变结果，不设计绝对必胜兵种。

## AI 与信息公平

UI 显示敌方上一波数量，不显示待出兵阵容。AI 接口只接收玩家上一波公开阵容、AI 自己的兵营和矿物，绝不接收模拟器或玩家编辑中的配置。开局和每次出兵后增量购买：兵营先保证两个盾卫，兵营总价加矿物达到 700 时带一名医疗兵，其余从通用输出和针对性反制池中抽取，买不起时用蜂群补足；射程低于 60 的放最前列空格，其他放最后列空格。与玩家使用完全相同的 `buy()` 校验。

固定种子 42 使首版便于复现。记录实际每波双方阵容，因此重放不依赖以后修改的 AI 算法；但必须使用相同规则版本。

## 原型边界与后续

当前无障碍物、复杂法术、复杂寻路和动态视角，0.1.8 已加入首个空军解放者；部队采用局部分离，拥挤时允许一定重叠。下一阶段先做真机触摸尺寸与性能调优、更多混编对局数据，再做权威服务器与好友房间，最后考虑账号、匹配和 iOS。不能把首版单元测试的克制胜利理解为完整的对战平衡结论。

## 医疗兵（规则 0.1.2）

125 预算、100 HP、轻甲、速度 36。每 0.5 秒为 160 距离内一名受伤友军恢复 12 HP（24 HP/秒），优先生命比例最低者，同分按稳定 ID。可以治疗其他医疗兵，不治疗自身或基地；不造成伤害。当前所有兵种都可治疗，原型不引入能量条或生物/机械限制。

医疗兵跟随己方最前方的不具备治疗技能的战斗单位，目标站位在其后方 90 距离。追赶发现范围（240）内的伤员时也不越过这条线；附近敌军进入该范围后，目标站位至少在敌军后方 100 距离，优先后撤，可移动治疗。目标位置受战场边界约束；医疗兵没有瞬移或碰撞屏障，移动速度、包围和战场边缘仍可能使其被攻击。没有战斗友军时退向己方基地。

治疗统一累加、按最大生命封顶，再应用本步伤害，过量治疗不充当护盾。AI 在兵营总价加矿物至少 700 时安排一名医疗兵在后排；玩家可自由配兵。UI 使用三列三行卡片、圆底十字图形和绿色治疗连线。

## 迫击炮架设（规则 0.1.4）

保留 mortar ID、150 预算、100 HP 和轻甲定位，改为高火力的自动架设炮兵。发现距离为射程的 150%（450）；射程内敌人数大于阈值 X（默认 2），或者连续两次扫描（间隔 0.5 秒）发现同一敌军 ID 仍在射程内，才开始架设。少量敌人刚进入射程时停下观察，不会直接开火。行进、架设中、已架设、收起中四种状态由模拟 tick 驱动。架设中可重新索敌，首次开火后才锁定；已架设时保持原地射击。只有射程内没有敌军、且 120% 射程（360）内没有正在靠近的敌军时才收起。该保持规则同样适用于架设途中，避免原目标被友军击杀后立即取消架设。收起完成后才能移动或重新架设；收起途中有敌军返回也不能跳过转换时间。收起会清空扫描记录，下次必须重新确认。

攻击基地同样需要架设，但基地是固定目标，可直接开始架设而不需要两次扫描。没有额外的近距离射击模式或最小射程；这版通过转换耗时和低生命值体现机动弱点。支架、架设/收起进度条和状态文字用于显示当前状态。原“远距离狙击克制迫击炮”的测试改为远距离炮兵优势，另有狙击手近距离突袭、架设前击杀的测试。

### 0.1.4 扫描与保持判定

密集敌军（大于 X）的触发每步检查，无需等下次定时扫描；少量敌军比较相邻两次扫描的 ID 交集，换成另一个敌人或中间扫描为空都不能沿用旧确认。X、扫描间隔、外围范围倍率均在 `data/units.json` 中配置。

是否接近使用上一模拟步的敌军位移与“敌军指向炮兵”方向的点积判断，不使用朝向图形、敌方锁定目标或单纯距离。120% 边界包含在内，静止、切向及远离不算接近；检测有最多一模拟步的延迟。所有单位使用同一份步初位移记录，不受处理顺序影响。保持架设不意味着扩大射程，外围敌军仍需进入 300 距离才能被攻击。

## 穿刺者（规则 0.1.5）

内部 ID `piercer`。175 预算、180 HP、重甲、速度 34；伤害 45，对轻甲 ×1.0、对重甲 ×1.5（67.5），攻击间隔 1.8 秒。射程固定为 260，地刺每秒前进 260，直线半宽 14（全宽 28）。初版数值需要实战平衡。

埋地耗时 1 秒，出土耗时 0.75 秒，转换和埋地状态不能移动。共用炮兵的两次扫描确认、超过 X=2 立即展开、120% 外围接近保持规则。埋地完成才能发射，首次发射后锁定主目标；埋地目前仅是状态和外观，未实现隐身，敌军仍可索敌和攻击。

地刺在发射时固定起点、方向、长度和伤害，下一模拟步才开始推进。每条地刺始终走满 260，即使主目标很近、死亡或移动，或穿刺者死亡，传播也不会中断或追踪转弯。到达沿途敌军时才造成伤害，每波每个敌人最多一次，不伤友军。敌军可在地刺抵达前移出路径躲避；进入已经扫过的区域不会被追溯伤害。

碰撞计算同时考虑单位在这一模拟步的移动和地刺前沿的推进，避免快速横穿路径漏判。射程末端精确截断；多道地刺独立结算。基地同样延迟受伤，以前沿碰到半径 20 的基地边缘为准。

配兵界面新增第八张卡片、虫形图标、埋地/出土状态及进度；地刺逐段绘制并短暂消退，呈现由近到远的传播。AI 可抽取穿刺者，并用迫击炮反制敌方穿刺者。

## 巨像与技能组合（规则 0.1.6）

内部 ID `colossus`。250 预算、400 HP、重甲、速度 28、射程 280（发现范围 420）。每 2.4 秒发动一次双重攻击，每击基础伤害 24；对轻甲 ×1.5（每束 36，两束合计 72），对重甲 ×1.0（每束 24，合计 48）。不需要架设。数值为待实战调整的原型起点。

开火时，以主目标当时位置为中心，沿垂直于“巨像→目标”方向建立长 180、全宽 28 的横向区域。两束从两端同时出发、相向穿过中心、继续走到另一端；速度 180，完整扫射耗时 1 秒。静止中心目标在开始推进后的 0.5 秒同时受到两击；侧面目标先后受到两击。方向和中心在开火时固定，不跟踪移动中的目标。

每束有独立命中记录，每名敌人每束至多受伤一次；不伤友军。移动可以躲避其中一束或两束，不保证命中。攻击发出后，即使主目标或巨像死亡，已发出的扫射仍继续；基地同样在波前到达后受伤。巨像攻击采用普通开火锁定与冷却规则，不在扫射期间追踪或转向。

界面新增第九张卡片、四足长腿外形与两束逐段推进的光束。AI 可选择巨像，并用破甲手反制巨像。横向密集阵形更易受到范围伤害，分散和近身破甲会影响收益。

当前复用关系：迫击炮 = deployment + 普通溅射；穿刺者 = deployment + line_attack(forward)；巨像 = line_attack(transverse) + multi_attack(count=2)；医疗兵 = healing。技能字段已迁入 `skills`，详见 [SKILLS.md](SKILLS.md)。突进、隐身、变形尚未实现；后续按实际行为添加对应模块和调度入口。

## 劫掠者与强化剂/命中减速（规则 0.1.7）

内部 ID `marauder`，依据用户提供的图片录入现有属性。名称为“劫掠者”，使用单体榴弹普通攻击；“优势对抗：重甲”仅为介绍，没有额外重甲伤害、仇恨或优先索敌规则。轻/重甲倍率均为 1，继续使用最近发现目标、开火锁定的通用行为。

| 图片属性 | 当前映射 |
| --- | --- |
| 560，部署 4 个 | 暂按单名 140 预算；一次放置一名，四名共 560，不新增建筑与批量部署 |
| 生命 125 | hp 125 |
| 攻击 26 | 每击伤害 26，单体，不挂载多重攻击 |
| 攻速 1.5 | 暂按每 1.5 秒一次攻击 |
| 射程 6 | range 168；按现有步枪兵射程 140 对应参考尺度 5，取每格 28；这是原型换算约定 |
| 移速 2.25 | speed 36；按现有步枪兵的 36 对应参考尺度 2.25，取倍率 16 |
| 重甲－生物、护甲 4 | 接入已有 heavy 标签；生物分类与数值护甲减伤未接入 |
| 仇恨、推进、补给、半径、建筑能量、阵营强化 | 当前没有对应机制，本次不接入 |

强化剂（`stimulant`）：交战第一时间自动使用，即敌军进入攻击范围且单位已允许开火时，无需等待本次普通攻击冷却归零。每次扣最大生命的 15%（劫掠者 18.75），持续 20 秒，攻速 +30%、移速 +50%。攻速加成使基础冷却按 1.3 倍消耗，理论攻击间隔 1.5/1.3 秒，20 Hz 模拟下连续攻击约每 1.2 秒一次；基础移速从 36 提升到 54。结束后仍在交战且当前生命严格大于扣血量则再次使用，不叠加，不提前续费；没有敌军、仅攻击基地或生命不足时不施放。效果不会因脱离交战提前消失；暂停/后台不消耗持续时间。

命中减速（`on_hit_slow`）：每次击中敌方单位后移速降低 50%，持续 2 秒；再次命中刷新持续时间，不叠乘。所有单位本步移动都确定后统一施加，从下一模拟步起作用满 40 步，避免处理顺序影响结果。普通攻击、溅射和传播攻击均可复用；传播攻击只有真正命中时才施加，不在发射时施加。基地不受减速，治疗单位的移动也遵守减速。强化剂与减速同时存在时移速为基础的 75%（36×1.5×0.5=27）。

两项能力均为独立技能模块，不依赖劫掠者 ID。强化剂扣血作为自身代价统一结算，不计为敌方输出；治疗决策仍依据步初生命，医疗兵从下一步起可治疗扣血。界面以橙色外环表示强化剂、脚下蓝色折线表示减速。

0.1.7 时全部单位都在地面；0.1.8 已加入空地过滤，劫掠者仍仅能对地。该版本不声称复刻《星际争霸 II》完整劫掠者或图片所属地图的平衡数值；上述价格与尺度是可调整的原型映射。外形使用自绘重装躯干与双侧发射器，不引用游戏素材；双侧外形不代表双重攻击。

配兵区每页最多九张卡片，可循环翻页，劫掠者位于第二页。翻页保留当前选择与阵容；直接选择某兵种时切换到其所在页。AI 可以购买劫掠者，并用现有破甲手反制敌方劫掠者。

## 解放者（规则 0.1.8）

参考用户提供的“解放者”图片，机制对照 [暴雪官方介绍](https://news.blizzard.com/en-us/article/19451932/introducing-the-liberator) 以及 [Liberator 模式说明](https://liquipedia.net/starcraft2/Liberator)。官方介绍说明飞行对空范围伤害、防卫对地高额单体伤害且不能攻击建筑；数值采用用户图片，不照搬当前天梯平衡。

- 内部 ID `liberator`，300 预算（0.1.9 起；0.1.8 按图片为 1200，等于满预算，整波只能有它一架）、180 HP、重甲、空中单位。不新增平台建筑或能量资源。
- 飞行模式：对空单次伤害 20，间隔 1.8 秒，射程 5→140；对空溅射半径暂取 42，移速 3.38→54.08。图片未标明双重攻击，此版每周期一次 20 伤害，不额外乘二。
