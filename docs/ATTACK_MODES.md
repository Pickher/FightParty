# 攻击模式与分段弹道（0.9.0）

0.9.1更新：下方0.9.0初始表为历史快照，当前武器参数以JSON/Excel为准。特战队员电磁步枪、特工两种弹药、坦克机动/攻城炮、地堡驻军枪兵的delivery为fixed/seconds=0，发射即命中，出手持续时间保留；地堡劫掠者仍为飞行榴弹。

医疗兵、哨兵、虚空辉光舰、基地防御改为delivery.type=beam，attack_duration=0.5、hit_count=1、interval=0、tick_interval=0.5、switch_delay=0.3。持续光束画面与周期结算分开：每0.5秒一次完整命中并扣一次护甲，不拆成0.05秒采样。例如虚空9对护甲3特战队员，每0.5秒结算6点生命伤害（无其他减伤时）。治疗使用模式healing=12，不回护盾；哨兵damage=9、shield_bonus=4，虚空damage=9、bonus.heavy=4，基地damage=300且保留true无视护甲。基础面板数值不因改表现而额外乘十。

光束首次接敌无切换等待，连续作用满0.5秒结算首轮；切换目标时清空未完成周期，等待0.3秒后重新累计0.5秒，未完成周期不转移给新目标。丢失目标时不结算；医疗兵优先保持仍受伤且在范围内的病人，减少无必要切换。攻速倍率缩短结算周期，单次完整伤害及护甲口径不变；默认攻速下严格0.5秒一次。光束不创建弹体或多段出手序列，普通伤害结算与治疗通道共用BeamService。

每个单位的attack_modes显式列出其全部普通武器模式，primary_mode选择默认武器。伤害、伤害类型、护甲/标签加成、段数、射程、轮后间隔和弹道只在模式内编辑；单位自身保留生命、护盾、护甲、移动等属性。非攻击支援单位也显式标注无普通攻击模式，主动法术的伤害仍属于各自技能。腐族保留原有实装状态，不新增其预留能力。

除雷神三模式采用用户指定值，新增持续时间和弹道速度是本作的初始设计，不声称是星际2原版数据。价格、每组数量、已有伤害与加成尽量保留；特工使用原来实际生效的30伤害弹药模式，移除未被使用的顶层40伤害。配置表的武器模式页可逐项调整。

## 时间与状态

第i段（从0开始）在windup + attack_duration×(i+1)/hit_count时发出；attack_duration不包含可选的额外前摇windup和后摇backswing，当前正式模式两者均为0。最后一段出手并完成后摇才进入interval等待，弹体飞行不延长攻击周期；无攻速加成时完整周期为windup+attack_duration+backswing+interval。攻速倍率同时缩短出手与轮后等待，不改变弹道速度。

AttackCycle记录本轮时长、冷却及序号，AttackSequence保存模式/加成快照并依次发射，Projectile保存独立弹体。未发射段随射手死亡或施法/收放中断而取消；已发出弹体不依赖射手存活。以步内偏移记录发射时间，因此20Hz模拟中的0.125秒不会逐段取整成0.15秒。伤害仍在每个固定步末统一应用，短于0.05秒的命中可能在同一步显示，逻辑时间不会累积漂移。

单体模式目标死亡后停止后续未发射段，已经发出的单体弹不转移伤害。范围模式continue_on_target_death=true时向目标最后位置打完本轮；追踪范围弹在目标死亡后冻结落点，每次爆炸按该次命中时的位置独立查询受击者。每段单独扣盾/护甲、触发命中技能；坦克60%/30%分圈溅射同样逐段应用。

弹道type：instant为出手时立即接触（近战），fixed按seconds固定延迟，distance按距离/speed决定飞行耗时，wave沿固定几何轨迹传播（可被横向移动躲避）。追踪弹在发射时确定飞行耗时，后续追踪不延长耗时；目标离开武器射程不撤回已发射弹。飞龙弹射及巢虫孵化在命中时触发，地刺/巨像按每段分别创建传播轨迹。治疗、范围法术、大和炮等独立技能保留自己的施法时间，不走普通武器间隔。
