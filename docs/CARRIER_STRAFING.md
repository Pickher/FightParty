# 航母与拦截机掠袭（整合至 0.13.0）

旧拦截机只用自己的 2 格武器射程索敌，发现范围为 3 格；航母在距离敌人约 8 格处放出飞机时，飞机通常看不到敌人，随后按母体依赖逻辑回到航母身边。此次让拦截机接收母舰作战目标，并使用独立的 `strafe_attack` 技能移动攻击。

## 行为

- 拦截机飞向目标附近的切入点，沿经过目标附近的航段飞过，在武器射程内完成一轮射击，再换一个角度切入。它不会停住等攻击，也不沿固定圆轨道绕行。
- 每架飞机独立选择航线，随机变化发生在航段之间；转弯速度受限，避免每帧突然换方向，机头随飞行方向显示。航线随机状态可随战报确定地重放。
- 目标死亡或离开母舰控制范围后重新选敌，没有合适目标时返航、随舰待命。攻击基地仍沿用原有合法性和伤害流程。
- 拦截机是有生命、护盾的真实空中单位。飞入敌方射程后，能被对空武器正常发现、锁定和击落；没有额外强制嘲讽或无敌状态。
- 航母本身仍没有普通攻击伤害。母舰死亡后，其依赖拦截机按原规则消失。

保留项目现有数值：最多 8 架、每 0.27 秒放出/补充一架，母舰发射距离 8、已发射飞机的目标控制距离 10；拦截机移速 10.5、射程 2，每轮 2 段、每段 8 点伤害，持续 0.2 秒后等待 2.14 秒。实际开火还需处于有效掠袭航段和射程内，不会因为换航线重置武器冷却。

本次没有增加真正的机库入库、机库补盾或付费补建循环。无目标的飞机只是返航随舰，仍保留实体和原有恢复规则。

## 组件与可调参数

`scripts/skills/strafe_attack.gd` 负责目标衔接、航段与飞行；伤害、两段出手、弹道、护甲和攻击冷却继续通过公共武器流程结算。其他需要类似掠袭的单位可复用该技能，按参数调整飞行方式。

在 `data/units/兵种配置.xlsx` 的「技能参数」页修改 `interceptor / skills/strafe_attack`：

| 参数 | 当前值 | 含义 |
| --- | ---: | --- |
| `pass_distance` | 3 | 目标中心到航段两端的半长度（格） |
| `lateral_spread` | 0.75 | 航段随机横向偏移上限（格） |
| `approach_angle_degrees` | 65 | 下一航段的偏转上限（度） |
| `turn_rate_degrees` | 540 | 最大转向速度（度/秒） |
| `arrival_radius` | 0.6 | 航点到达阈值下限（格）；运行时至少覆盖一步位移及最小转弯半径，避免围着航点打转 |
| `follow_radius` | 1.2 | 无目标时的待命跟随范围（格） |

武器数值仍在「武器模式」页，航母载机数量及控制距离仍属于航母的 `summon` 技能参数。调整航线不会自动修改这些数值。

## 参考与项目取舍

[Liquipedia 的《虚空之遗》拦截机页](https://liquipedia.net/starcraft2/Interceptor_%28Legacy_of_the_Void%29)描述拦截机自动掠袭（strafe）母舰目标；[航母页](https://liquipedia.net/starcraft2/Carrier_%28Legacy_of_the_Void%29)列出发射和控制规则。项目导入的沙漠风暴 `WeaponData.xml` 将 `InterceptorBeam` 定义为 `CWeaponStrafe`，`EffectData.xml` 的单段伤害覆盖为 8。参考文件位置见 [原图数据说明](../reference/desert-storm/README.md)。

[暴雪 5.0.11 正式补丁](https://news.blizzard.com/en-us/article/23893118/starcraft-ii-5-0-11-patch-notes)降低了拦截机被自动攻击的优先级，因此此次通过真实位置与可攻击实体实现吸引火力，不增加强制嘲讽。

航段生成是项目对掠袭行为的近似实现，资料没有提供原作完整轨迹算法。原作多人版控制距离 12，以及原图机库初始数量等差异，本次没有顺带覆盖；载机数量、经济和既有战斗数值保持当前项目配置。
