## 行为

- 电脑布阵板：左键单击一名；双击全部同类（跨组）；左键拖框选择中心落在框内的兵员。框内同时有建筑与部队时只选部队。建筑单独选中仅供显示，不参与位置提交。左键绝不提交布置。
- 右键对当前选择进行布置：松开点附近确定性紧凑散布；按住至少 300ms 且移动至少 24 设计像素切换共享拖线。快速短拖仍是松开点散布。散布使用局部固定种子，不消费战斗随机数。空间不足报错并保留原布局，不做部分提交。
- 手机只走原生触摸，保持单兵点选、空白点放、长按拖线。第二指取消并等待全部抬起；模拟鼠标不会重复操作。触屏电脑也可使用同一触摸流程。
- Esc 优先取消当前手势，再次关闭面板；移出板松开、失焦、布局重建、切后台、切换界面或输入来源都取消。手势中滚轮按键取消该手势，不添加布阵滚轮功能。
- 显式选择在关闭/重开面板、重新购买、数量按钮与下一批时清除，防止旧 cell/member 键误选新兵。选区不修改购买组，不控制已在战场上的实体。
- WASD 为设计像素速度，按镜头比例换算，指数加速/减速并积分；对角不加速。世界边界钳制，遇边停止该轴惯性；缩放、焦点/模态变化、鼠标导航清除输入。只有用户键盘平移后关闭跟随。医疗机沿既有视口相机同步，无独立相机偏移。
