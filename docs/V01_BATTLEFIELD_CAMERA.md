# V01：战场大视图、近景与小地图

2026-11-15（北京时间）。分支 `cloud/v01-battlefield-camera` 已接入 `cloud/test` 的 `2b468e0`（v0.11.4）。状态：**实现完成，待体验验收**；本次未运行 Godot、资源导入、游戏、测试、模拟或打包。此文的尺寸是源码推算，不是截图或真机测量。基线原有测试记录不能代替 V01 验收。

用户直接安排 V01，故沿用当前种族和兵种范围实施通用表现，不等待 R02，也不修改正式/实验种族入口。保持 v0.11.4 的战斗规则与数据版本，包括基线新接入的恶火间距和接敌逻辑；这是独立的 UI 特性分支。

## 操作

| 操作 | 效果 |
| --- | --- |
| 战斗大视图 / 布阵 | 隐藏/恢复下方布阵、选兵和敌情区；战场高度从 352 增至 640 设计像素。普通近景切换保留单位显示尺寸，全图状态继续适配全图 |
| 开始准备 | 自动展开战斗大视图，启用近景并跟随己方前锋/交战；“布阵”按钮随时可返回修改下一波 |
| 全图 / 近景 | 全图等比显示整个地图；近景恢复适合辨认小兵的显示大小 |
| 己方 / 中线 / 敌方 | 用近景定位对应出兵点或地图中心 |
| 跟随交战 | 开启时先定位最近交战，再平滑跟随；再次点击停止跟随。没有近期交火时跟随己方最靠前的存活非建筑单位，暂无部队时回己方出兵点 |
| 拖动战场 | 手动平移并停止自动跟随；滚轮及 + / − 按钮缩放，缩放本身保留跟随状态 |
| 小地图点按 / 拖动 | 移动镜头并停止跟随；全图状态下点击会恢复近景。白框表示当前看见的世界区域 |
| 建造防御塔 | 自动展开视图并定位己方宝库附近，停止跟随；可以用小地图/导航按钮重新定位。只有点击实际战场落点才尝试建塔；小地图、标题和边框不会建塔 |
| 经济 / 玩法说明 / 暂停 | 保持原有操作。布局按钮不推进时间、不修改布阵，也不自动暂停战斗；经济与说明页按原逻辑暂停 |

大视图工具栏保留布阵、经济、建塔和镜头按钮。选兵卡片仍使用原有简短简介，没有混入武器详情、模型尺寸等额外内容。完整双指手势、手机专用布阵布局等属于 U01，不在本次实现范围内。

## 视图与尺寸

| 项目 | 当前设计 |
| --- | --- |
| 设计画布 | 1440×900 |
| 布阵战场 | `(70,157)`，1300×352 |
| 展开战场 | `(70,157)`，1300×640；战场面积约为原来的 1.82 倍 |
| 近景 | 24 设计像素/格；0.8 格单位的逻辑主体宽约 19.2 设计像素 |
| 默认 1152×720 窗口 | UI 等比缩小为 0.8；上述主体约 15.36 显示像素，旧默认约 3.82 像素 |
| 近景视野 | 宽约 54.17 格；布阵高约 14.67 格、展开高约 26.67 格 |
| 最大放大 | 48 设计像素/格 |
| 小地图 | 面板 242×170，地图内容按真实 196:118 比例居中留边 |

单位图集含透明留白，实际可见轮廓会小于或不同于逻辑主体；这些数字不保证所有小屏设备可读。Windows 默认窗口及 Android 横屏仍需用户体验验收。

所有界面统一用 `min(窗口宽/1440, 窗口高/900)` 等比缩放并居中留边。画面绘制与鼠标/模拟触摸使用相同的正反变换，宽屏不再分别拉伸两个方向。原型采用留边保持比例，不承诺用满每种宽高比的全部屏幕。

## 接入与边界

- `scripts/main.gd` 管理布局、屏幕/设计/世界坐标、相机、小地图及输入。`_battle_rect()` 是战场区域的统一入口；`SubViewport` 尺寸随布局同步。
- `scripts/battle_view.gd` 使用动态视口尺寸；名字、血条、状态和武器标签按实际设计像素密度决定是否显示，不再因布局改变相对缩放倍数而突然消失。
- 普通攻击、推进线、大和炮、弹射、爆炸和非治疗持续光束提供交战焦点。镜头只读当前场上状态和已有事件，不读敌方下一波阵容，不影响模拟结果。
- 小地图显示场上单位位置，沿用当前没有迷雾的规则；首次交战前敌军只画统一灰点，不暴露兵种、空地、建筑类别、血量或未来阵容。基地和中央井为地图固定信息。
- 布局/弹窗/操作变化后清空旧按钮与拖动状态，等重绘后重新接收点击。开局、说明、经济、确认和结算弹层阻断小地图/战场操作；后台与窗口大小变化也清理拖动。
- 建塔时镜头不自动跟随。小地图区域及选址说明条不参与落塔和预览；坐标合法性仍由原 `BattleSim.build_tower()` 校验。
- 普通近景切换布局保留比例；如果原视野比新布局的全图适配还小，则以新布局完整显示地图为下限。全图点击小地图后转为近景定位。
- 地图、单位、武器、碰撞、射程、AI、经济及战报规则均未改动。字体资源重新生成以覆盖新增中文。
