## 性能数据

Windows：Intel Core i5-14600KF、NVIDIA GeForce RTX 4070 Ti SUPER，Compatibility / OpenGL 3.3，测试窗口 1152×720。

- 200 单位、600 模拟步：9606.69 ms，总平均 16.011 ms/步，低于 20 Hz 的 50 ms/步预算。这是模拟耗时，不能当作画面帧率。
- 200 单位真实渲染采样：601 帧 / 10.013 秒，平均 60.02 FPS，期间推进 201 个模拟步。
- 高生命单位用于保证压力场景不因互相击杀而快速减员。实际常规规则最多约 144 单位共存。

## Android 验证边界

本次没有连接 Android 真机，不能宣称达到真机 30 FPS。模拟器不能代替实机功耗、温度、驱动兼容性和手指操作验证。

原 Compatibility APK 在模拟器 GLES 后端出现 `GL_MAX_FRAGMENT_UNIFORM_VECTORS (261)` 着色器错误，故 Android 已调整为 Mobile/Vulkan。Windows 仍使用 Compatibility。安卓最终渲染、实际触摸和后台恢复验证尚未完成；电脑自动关机中断了该部分测试，最后一次截图未完整写入，不作为通过证据。

交付的 APK 是开发测试包。正式发行前仍需在真实 Vulkan 安卓设备上进行安装、横屏布局、触摸、切后台、完整一局和 200 单位性能测试。核心后台暂停逻辑已有程序化测试，但与真实系统生命周期验证应分开记录。
