FightParty 朋友调试包
版本：2026-11-02；适用于 Windows 10 / 11 的 Intel、AMD 64 位电脑。

一、先运行游戏（不需要 Python）

1. 右键收到的 ZIP，选择“全部解压”。不要在压缩软件里面直接双击运行。
   建议放到 D:\Games 或桌面等自己有读写权限的位置。
   整个 FightParty 文件夹可以一起移动，里面的文件夹不要单独拆开。
2. 进入解压后的 FightParty 文件夹，双击“开始游戏.cmd”。
   如果 Windows 隐藏扩展名，看到的名称可能只有“开始游戏”。
3. 会先出现一个黑色窗口，显示“正在准备游戏资源”。
   第一次需要生成字体、图标缓存，请耐心等待，不要关闭这个窗口。
   随后会自动出现游戏窗口。无需安装 Godot，无需打开任何编辑器。
4. 进入游戏后，先点击下方的兵种卡片，再点击左下方的布阵格子放兵。
   同一行越靠右越接近前线。已有默认阵容，也可以直接开始。
5. 点击画面上的“开始准备”，开始 30 秒准备倒计时。
   倒计时结束双方自动出兵，以后每 30 秒出一波。战场上的兵不能手动控制。
   调整下方阵容只影响下一波；超预算的配置会被拒绝。
6. 空格键暂停 / 继续；Esc 查看游戏说明。结算后点击“调整阵容，再来一局”可重开。
7. 退出时关闭游戏窗口即可。黑色窗口正常情况下随后自动关闭。

如果你只想先试玩，到这里就够了，不用安装 Python。

二、修改表格前，需要安装什么

1. Excel 或 WPS 表格：用来编辑 .xlsx 文件，任选一种即可。
2. Python：推荐安装 Python 3.13.x 标准版，Windows installer (64-bit)。
   在 3.13 系列中选择官网提供的正式补丁版本，不选预览版、ARM64、32-bit、
   embeddable package 或 free-threaded 实验版本。
   官方下载页：https://www.python.org/downloads/windows/
   安装第一页勾选“Add python.exe to PATH”（有些版本写 Add Python to PATH），
   保留 Python Launcher 的默认安装选项，然后点 Install Now。
   官方安装说明：https://docs.python.org/3.13/using/windows.html
   安装完关闭之前的黑色窗口，再重新双击“导入兵种.cmd”。
   不需要安装 pip 包、代码编辑器、Git、GitHub 或 Codex。

本包不包含 Python 安装包或 Python 运行时。Godot 引擎已放在 engine 文件夹中。
导入脚本兼容 Python 3.8+；新安装请按上面的 3.13.x 版本选择。

三、修改现有兵种，并在游戏里看到变化

1. 先关闭正在运行的游戏。
2. 双击“编辑兵种表.cmd”，或者直接用 Excel/WPS 打开 data\兵种配置.xlsx。
3. 打开“兵种”页。从第 6 行开始，一行就是一个兵种。
   第 4 行是中文说明，第 5 行是程序使用的英文列名，不要改动第 5 行。
4. 比如先把盾卫的 hp（生命值）从 480 改成 600，其他字段保持原样。
5. 按 Ctrl+S 保存 Excel，建议关闭表格后再进行下一步。
6. 双击根目录“导入兵种.cmd”。它会检查整张表，然后更新 data\units.json。
   看到“已写入”表示这次修改已导入。
   看到“数据相同，未写入”表示表格与游戏配置已经一致，也属于正常结果。
   看到“导入失败”请按提示修正，失败时不会替换原来的配置。
7. 按任意键关闭导入窗口，再双击“开始游戏.cmd”。
   进入游戏后放置这个兵种、点击“开始准备”，观察新单位的生存与战斗效果。

注意：保存 Excel 本身不会更新游戏。必须“保存表格 → 导入 → 重新启动游戏”。
游戏内的“调整阵容，再来一局”不能替代完全退出并重新启动。
不需要重新打包 EXE/APK；本包从源码直接读取修改后的 JSON。

四、添加一个新兵种

1. 在 Excel 的“兵种”页，复制最接近你想要效果的一整条兵种数据行。
2. 粘贴到最后一条兵种下面的空行，保留全部字段。
3. 把新行 id 改成唯一的英文 ID，例如 friend_raider。
   ID 只能包含小写字母、数字、下划线，并以字母开头。
   不能与已有 ID 重复，也不能叫 move 或 erase。
4. 把 name 改成你想显示的名字，再改价格、生命、伤害、射程、移速等数值。
5. 保存，关闭表格，运行“导入兵种.cmd”，再运行“开始游戏.cmd”。
6. 兵种卡片超过 6 张后，点击卡片区域的“下一页”查看新增兵种。
   新兵种默认显示为圆形，也会进入 AI 的普通购买池。

不要删除或修改已有兵种的 id，存档和 AI 可能引用它。显示名称 name 可以修改。
全部字段都要填写，不能只复制名称和数值的一部分。不要在数据区添加合计行。
若排序，请整行一起排序，不要只排序某个数值列。

五、几个容易填错的字段

cost：价格，必须是正整数。高于当前波次预算的单位买不起。
hp：生命值，必须大于 0。
interval：攻击间隔，单位秒，越小攻击越快，必须大于 0。
armor：只能填 light（轻甲）或 heavy（重甲）。
damage：单次基础伤害。实际攻击单位时还会乘相应护甲倍率。
light_multiplier / heavy_multiplier：对轻甲 / 重甲的伤害倍率。
range / speed：射程 / 移速，使用游戏世界单位，不是电脑屏幕像素。
splash：溅射半径。0 为单体攻击，正数为范围攻击。
color：6 位颜色文本，例如 ffcc66，不带 #；纯数字颜色也要保留文本格式。
symbol：单个字符，例如 A。
role / counter：定位、克制的界面说明文字；它们不会自动增加战斗能力。

其他数值也不能为负；可以填 0 的字段不要留空。不要输入公式、百分号或单位后缀。
每个字段的详细解释在 Excel 的“填写说明”页。
把定位写成“刺客”不会自动获得绕后、隐身或嘲讽，这些能力需要后续开发。
名字、定位说明过长可能超出游戏卡片，建议保持简短。

六、怎么恢复改坏的数值

只要有数值变化，导入时会把原配置备份到 data\backups。
先关闭游戏，找到需要恢复的 units-时间戳.json，复制到 data 文件夹，
把文件名改成 units.json 并覆盖当前配置，再启动游戏。
同时也要把 Excel 改回对应数值，否则下次导入会再次覆盖游戏配置。
最简单的彻底恢复方法：把原 ZIP 重新解压到一个新的文件夹，从原始表重新开始。
恢复兵种数值不会自动清除游戏保存的阵容；必要时在游戏中点击“清空阵容”重新布置。

七、运行不成功怎么办

找不到 Python：重新安装 Python 3.13.x，勾选 PATH；关闭旧窗口后重试。
导入提示第几行错误：按提示检查对应字段，保存 Excel 后再导入。
表格没有打开：安装 Excel 或 WPS，也可以在软件里手动打开 data\兵种配置.xlsx。
没有看到游戏窗口：确认完整解压，等待资源准备完成，不要连续重复双击。
启动失败：把 logs 文件夹里的“资源准备.log”和“游戏运行.log”发给项目负责人。
游戏白屏、黑屏或显卡报错：先更新显卡驱动；仍失败则发送日志与电脑系统、显卡型号。
改完没有变化：确认改的是当前解压目录里的表格，已保存、已导入、已完全退出再重开。
新兵种买不起：检查 cost 与当前波次预算；第一波预算为 600。

八、测试结果怎么反馈

把修改后的 data\兵种配置.xlsx 发回来，再附上你观察到的情况：
改了哪个兵种、改了什么、对面是什么阵容、实际效果、你认为哪里需要调整。
有异常时附上截图和 logs 中的日志。一般不需要发送整个调试包。
多人同时新增兵种时建议用不同前缀，例如 friend_，避免 ID 重名。
