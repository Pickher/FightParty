# 折叠部队配置与单兵排布

## 操作

战斗默认使用大视图，下方点「部队配置」打开面板。「收起，返回战场」关闭面板。当前离线人机局在面板打开期间暂停模拟和单位动画；关闭后恢复原来的开始/手动暂停状态，不会把手动暂停的对局自动继续。

| 操作 | 效果 |
| --- | --- |
| 现有部队 | 按兵种显示已购买组数和实际人数；人数由 `spawn_count` 决定，当前特战队员每组 4 名、哨兵每组 2 名 |
| 招募部队 | 选择本页兵种查看简介。招募按钮列出对应的兵种、人数和每组资源价格。资源不足时提示差额，资源充足且兵营有空位时可购买并选中新兵 |
| 1 名 / 一组 / 全部 / − / + | 选择同兵种本次要安排的人数，不改变已购买数量 |
| 轻点空处，或只拖很短距离后松手 | 将一名士兵放在落点附近。选多名或「全部」时，所选士兵在落点周围随机、紧密地散开，同时给同层单位留出空间 |
| 长按并拉出足够距离后松手 | 按住至少 0.3 秒，且起点到当前手指的距离至少达到 24 个界面设计像素（按 1440×900 换算）。满足两项条件后才出现排布线，松手时沿线均匀排布。线段容不下整批时向后增加排数 |
| 下一批 | 轮换同兵种下一批；一次成功布置后也会自动选下一批，最后一批之后回到开头 |
| 点击已有士兵 | 单名模式下选中点到的士兵，可再点空处修改位置。已选多名时保留当前批次，点在其他士兵身上也会围绕落点散布 |
| 一键自动排布 | 依据现有兵种的射程和技能，将近战放前面、普通火力居中、远程/部署/召唤靠后、治疗和光环辅助最后；随后可手动微调 |
| 拖出布阵框松手 / 右键 / 取消本次拖线 | 放弃未提交的拖线，保留原布局 |
| 格阵管理 | 返回原有组槽位界面，用于移除、退款、清空与旧操作 |

亮圈表示当前批次。点放会就近寻找空位，在边缘向部署区内散开。拖线预览用绿色或红色表示沿线能否放下整批。若整批放不下，所有成员保留原位置。空中和地面分层排布，允许两层位置重合。

所有位置调整只影响**后续波次**的出生位置，不能指挥已经出场的部队。整组购买、出场状态及退款规则不变；取消一组会移除其全部成员，即使这些成员已分散在不同位置。已有单兵坐标的组在旧格阵中「移动位置」只改变组槽位归属，实际单兵位置请在新面板修改。

## 布阵范围与布局

布阵范围由 `BattleSim.deployment_bounds()` 根据出生区域、现有实装兵种的体积与组内展开留白计算，再裁到地图和己方半场；当前数据为相对出兵中心的 28×28 格。界面的「前线 →」是本方朝敌方的方向，敌方出生时按现有地图规则镜像。

排布使用 `max(模型宽, 模型高, 碰撞直径) / 2` 作为占位半径，同层成员之间额外留 0.1 格。旧格阵原有重叠可以保留，真正移动的成员必须通过占位检查。自动排布采用确定性的分层、分职责列排法，再把整队居中；这不是最密装箱算法，兵力过多时可能需要手动分批调整。

此版本实现直线宽度与多排展开，没有曲线队列、任意旋转队形、战中移动命令或双指布阵手势。小屏可读性、手指误触率和满编时流畅度仍需实际设备确认。

## 数据与接口

- `scripts/formation_panel.gd`：独立面板、名单、批次、输入与预览；通过模拟接口购买和排布。
- `scripts/formation_layout.gd`：无节点依赖的排布几何、同层占位校验与自动排布。
- `deployment_members(team)`：将购买组展开为 `{cell, member, kind, position, radius, layer}`；`position` 是相对本方出兵中心、尚未镜像的坐标。
- `arrange_members(team, placements)`：接收 `{cell, member, position: [x, y]}`，全部合法才应用。它不走会卖出/买入的 `submit_formation()`，也不改变钱包、组数、`deployed` 或场上单位。
- 兵营条目可带 `member_positions: [[x, y], …]`，按组内成员序号保存。首次成功排布同时记录其他现有成员当前位置，避免后续购买改变旧格阵中心列时挪动已排好的士兵。
- `settings.cfg` 的各族最近阵容包含这些可选位置；仍是下局阵容设置，不是当前战斗的中途存档。恢复时先按原规则购买，再经 `restore_deployment(team, placements)` 校验布局；仅在 `tick == 0` 且 `wave == 0` 可用，检查编号、每个保存组的成员完整性、有限坐标和边界，允许保留旧格阵既有重叠。人数或坐标不合法时提示并使用默认队形，不靠坐标数据免费获得单位。
- 战报新增 `arrange_members` 和开局专用的 `restore_deployment` 动作，波次阵容保留可选 `member_positions`；`apply_action()` 可重放排布。没有位置的旧阵容仍走原格阵出生算法。旧版本程序不支持新动作，重放继续要求规则版本一致。
